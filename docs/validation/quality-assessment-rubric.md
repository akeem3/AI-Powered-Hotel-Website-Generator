# Quality Assessment Framework

## Evaluation Rubric (1-10 Scale)

### 1. Contract Compliance (30% Weight)
- **10**: Passes all ZOD validations (Strict), zero warnings.
- **7-9**: Passes validations, minor checks needed.
- **4-6**: Fails some validations but fixable.
- **1-3**: Major validation failures.
- **0**: Unparseable.

### 2. Relevance to Hotel Type (25% Weight)
- **10**: Perfect alignment with hotel type/audience.
- **7-9**: Strong alignment, minor gaps.
- **4-6**: Partial alignment.
- **1-3**: Poor/Irrelevant.

### 3. Content Quality (20% Weight)
- **10**: Compelling, on-brand, error-free.
- **7-9**: Good quality, minor improvements possible.
- **4-6**: Generic or formulaic.
- **1-3**: Poor/Broken.

### 4. Design System Compliance (15% Weight)
- **10**: Perfect CVA variant usage.
- **7-9**: Minor inconsistencies.
- **1-6**: Conflicting styles.

### 5. Completeness (10% Weight)
- **10**: All required components present.
- **1-9**: Missing elements.

## Calculation
`Overall = (Compliance * 0.3) + (Relevance * 0.25) + (Content * 0.2) + (Design * 0.15) + (Completeness * 0.1)`

## Thresholds
- **Production Ready**: >= 8.5
- **Acceptable**: 7.0 - 8.4
- **Needs Improvement**: < 7.0
