# Story 1.9: ZOD Contract Development for Core Components

> **Epic:** Epic 1 - Core Infrastructure with Contract System
> **Status:** Done
> **Priority:** High
> **Story Points:** 6
> **Version:** 1.0
> **Created:** 2025-10-23

## 1. The "Why" (Rationale)
This story provides the contract validation foundation that enables:

- Runtime type safety for all component configurations
- LLM output validation with detailed error messages
- Prevention of invalid component compositions
- Automatic error recovery and fallback mechanisms
- Foundation for progressive enforcement strategy
- 50% reduction in generation failures and debugging time

## 2. The "What" (Description)
**As a** developer implementing the contract-based component system,

**I want** to create formal ZOD schemas for all core components with runtime validation,

**So that** LLM-generated component configurations are guaranteed to be type-safe and compatible.

### AC2: Contract Integration Layer

- [x] Create `src/lib/contract-validation.ts` with validation utilities:
  ```typescript
  export function validateComponentConfig<T>(
    contract: z.ZodSchema<T>,
    config: unknown
  ): ValidationResult<T> {
    const result = contract.safeParse(config);
    if (result.success) {
      return { success: true, data: result.data };
    } else {
      return {
        success: false,
        errors: result.error.issues,
        message: formatValidationErrors(result.error.issues)
      };
    }
  }
  ```
- [x] Implement validation result formatting for LLM feedback
- [x] Add validation caching for performance optimization
- [x] Create validation middleware for component instantiation

### AC3: Enhanced Component Wrapper

- [x] Create HOC for adding runtime validation to existing components:
  ```typescript
  export function withValidation<T>(
    Component: React.ComponentType<T>,
    contract: z.ZodSchema<T>
  ) {
    return React.forwardRef<any, T>((props, ref) => {
      if (process.env.NODE_ENV === 'development') {
        const validation = validateComponentConfig(contract, props);
        if (!validation.success) {
          console.warn('Component validation failed:', validation.errors);
        }
      }
      return <Component {...props} ref={ref} />;
    });
  }
  ```
- [x] Apply validation wrapper to core components
- [x] Add development-time validation with detailed error messages
- [x] Ensure zero performance impact in production
