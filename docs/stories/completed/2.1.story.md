## 1. The "Why" (Rationale)
Expands homepage component diversity to 8 components, providing sufficient variation for Epic 2's validation testing while covering essential hotel website elements:

- **Visual Showcase:** Image galleries demonstrate hotel quality and ambiance
- **Social Proof:** Testimonials build trust and credibility with prospective guests
- **Amenity Discovery:** Clear display of facilities aids booking decisions
- **Validation Foundation:** 8 components provide diversity for LLM generation testing
- **Composition Testing:** 3 layout variants per component (9 total) validate architectural flexibility

**Epic 2 Validation Context:** This story is intentional overengineering for validation purposes. The 9 layout variants (3 per component) test LLM composition capabilities, ZOD schema robustness, and AssemblyAgent flexibility before Epic 7 automation.

## 2. The "What" (Description)
**As a** hotel website visitor,
**I want** to view hotel image galleries, guest testimonials, and amenity listings,
**So that** I can make informed booking decisions based on visual content, social proof, and available facilities.

## 3. The "How" (Acceptance Criteria)
### AC1: Image Gallery Component

**Functional Requirements:**
- [x] Display multiple images in responsive grid layout
- [x] Support click-to-expand lightbox functionality
- [x] Lazy load images for performance
- [x] Handle both desktop (.webp) and mobile (.m.webp) image formats
- [x] Provide thumbnail navigation in lightbox mode

**Layout Variants:**
- [x] **Grid layout:** 2×2 mobile, 3×3 desktop
- [x] **Masonry layout:** Pinterest-style, 2 columns mobile, 3 columns desktop
- [x] **Carousel layout:** Horizontal scroll with snap points

**Technical Requirements:**
- [x] Component follows Epic 1 patterns (TypeScript, responsive, accessible)
- [x] Props interface defined with clear types
- [x] Unit tests covering all three layout variants
- [x] Accessibility: keyboard navigation, ARIA labels, focus management
- [x] Performance: Images lazy load, no layout shift (aspect ratio preserved)

**File Structure:**
```
web-app/components/blocks/ImageGallery/
├── index.tsx                 # Main component with variant selection
├── GalleryGrid.tsx          # Grid layout implementation
├── GalleryMasonry.tsx       # Masonry layout implementation
├── GalleryCarousel.tsx      # Carousel layout implementation
├── Lightbox.tsx             # Full-screen image viewer
├── GalleryThumbnails.tsx    # Thumbnail navigation
└── ImageGallery.test.tsx    # Unit tests
```

**Props Interface:**
```typescript
interface ImageGalleryProps {
  images: Array<{
    id: string;
    desktopUrl: string;      // .webp format
    mobileUrl: string;       // .m.webp format
    alt: string;
    caption?: string;
  }>;
  layout: 'grid' | 'masonry' | 'carousel';
  columns?: 2 | 3 | 4;       // Desktop column count
  aspectRatio?: 'square' | 'landscape' | 'portrait';
  enableLightbox?: boolean;
  className?: string;
}
```
