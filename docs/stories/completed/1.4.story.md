# Story 1.4: Core Display Components with Mock Data

> **Epic:** Epic 1 - Core Hotel Website Infrastructure
> **Status:** Done
> **Priority:** High
> **Story Points:** 6
> **Version:** 1.0
> **Created:** 2025-10-22

## 1. The "Why" (Rationale)
This story provides the essential visual presentation components that enable:

- Strong first impression and brand identity through hero section
- Effective room comparison and selection through room cards
- Visual appeal that drives booking conversions
- Responsive design patterns for LLM reference implementation
- Component reusability across different layouts and pages
- Foundation for future component enhancements

## 2. The "What" (Description)
**As a** visitor browsing The Sterling Executive hotel website,
**I want** to see impressive visual components (hero section and room cards) that showcase the hotel's brand and room offerings,
**AND** view a comprehensive collection of available rooms in an organized layout,
**So that** I can immediately understand the hotel's value proposition and compare available room options effectively.

### AC8: ZOD Contract Implementation

- [x] Create ZOD schemas for HeroSection component:
  ```typescript
  export const HeroSectionContract = z.object({
    title: z.string().min(1).max(100),
    subtitle: z.string().min(1).max(200),
    description: z.string().max(500).optional(),
    primaryCTA: z
      .object({
        text: z.string().min(1).max(50),
        href: z.string().url(),
      })
      .optional(),
    secondaryCTA: z
      .object({
        text: z.string().min(1).max(50),
        href: z.string().url(),
      })
      .optional(),
    background: z.enum(["solid", "gradient"]).default("solid"),
    className: z.string().optional(),
  });
  ```
- [x] Create ZOD schemas for RoomCard component:
  ```typescript
  export const RoomCardContract = z.object({
    room: z.object({
      id: z.string().uuid(),
      name: z.string().min(1).max(100),
      type: z.string(),
      price: z.number().positive(),
      capacity: z.number().positive().max(10),
      amenities: z.array(z.string()),
      image: z.string().url().optional(),
      description: z.string().max(500).optional(),
    }),
    variant: z.enum(["compact", "detailed", "grid"]).default("detailed"),
    onBookNow: z.function().optional(),
    onViewDetails: z.function().optional(),
    className: z.string().optional(),
  });
  ```
- [x] Create ZOD schemas for RoomCardList component:
  ```typescript
  export const RoomCardListContract = z.object({
    rooms: z.array(z.any()), // Array of room data objects
    variant: z.enum(["compact", "detailed", "grid"]).default("detailed"),
    columns: z.object({
      mobile: z.number().default(1),
      tablet: z.number().default(2),
      desktop: z.number().default(3),
    }).optional(),
    className: z.string().optional(),
  });
  ```
- [x] Add runtime validation to components (development mode only)
- [x] Register components in component registry with metadata
- [x] Test contract validation with valid and invalid inputs
