# Hotel Website Builder Scripts

This directory contains scripts for building hotel websites from generated JSON configuration files.

## Overview

The scripts in this directory take the JSON configuration files generated by Epic 7's LangGraph workflow (stored in `output/`) and build complete, static hotel websites using the ComponentRenderer system implemented in Story 7.11.

## Available Scripts

### 1. `build-from-config.sh` - Main Build Script

The primary script for building websites from JSON configs.

#### Usage

```bash
./build-from-config.sh [options]
```

#### Options

| Option | Description |
|--------|-------------|
| `-c, --config FILE` | Specific JSON config file to use (default: latest) |
| `-a, --all` | Build websites for ALL JSON configs in output/ |
| `-o, --output DIR` | Output directory for built sites (default: ./dist) |
| `-p, --production` | Production build (minified, optimized) |
| `-d, --dev` | Development build with dev server |
| `-h, --help` | Show help message |

#### Examples

```bash
# Build from the latest config file
./build-from-config.sh

# Build from a specific config file
./build-from-config.sh -c output/homepage-config-lucky-tuna-boutique-hotel-v1768356990686.json

# Build websites for ALL config files
./build-from-config.sh --all

# Production build with custom output directory
./build-from-config.sh --production -o ./my-builds

# Start development server (live preview)
./build-from-config.sh --dev
```

### 2. `quick-build.sh` - Quick Build Shortcut

A simplified script for quick builds from the latest config.

#### Usage

```bash
./quick-build.sh [dev]
```

#### Examples

```bash
# Build production website from latest config
./quick-build.sh

# Start development server
./quick-build.sh dev
```

## How It Works

1. **Read JSON Config**: The script reads a `HomepageConfig` JSON file from the `output/` directory
2. **Prepare Environment**: Copies the config to the Next.js public directory and sets environment variables
3. **Build Next.js App**: Runs `npm run build` to create an optimized production build
4. **Export Static Pages**: Uses `next export` to generate static HTML files
5. **Copy to Output**: Moves the built files to the specified output directory

## Output Structure

When building with `--all`, the output directory structure looks like:

```
dist/
├── index.html                           # Index page listing all websites
├── lucky-tuna-boutique-hotel/           # Website 1
│   ├── index.html
│   ├── homepage-config.json             # Reference config
│   ├── _next/
│   │   └── static/                      # Next.js assets
│   └── ...
├── ocean-breeze-resort/                 # Website 2
│   ├── index.html
│   └── ...
└── final-verification-hotel/            # Website 3
    ├── index.html
    └── ...
```

## JSON Config File Format

The input JSON files follow the `HomepageConfig` schema:

```json
{
  "generationId": "budget-family-friendly-v1",
  "timestamp": "2025-12-19T10:30:00Z",
  "hotelParameters": {
    "hotelType": "budget",
    "targetAudience": "family",
    "brandPersonality": "friendly",
    "hotelName": "Lucky Tuna Boutique Hotel",
    "location": "Sri Lanka"
  },
  "components": [
    {
      "type": "navigation",
      "variant": { "navStyle": "solid", "navLayout": "compact" },
      "props": { ... },
      "order": 0
    },
    {
      "type": "hero",
      "variant": { "style": "modern", "layout": "centered" },
      "props": { ... },
      "order": 1
    }
    // ... more components
  ]
}
```

## Supported Component Types

The builder supports all 8 component types from Epic 1/2:

- `navigation` - Navigation bar with links
- `hero` - Hero section with headline and CTA
- `rooms` - Room listings with pricing
- `gallery` - Image gallery
- `amenities` - Hotel amenities display
- `testimonials` - Customer testimonials
- `booking` - Booking widget
- `contact` - Contact form

## Development vs Production Mode

### Development Mode (`--dev`)
- Starts Next.js dev server on http://localhost:3000
- Hot reload enabled
- Detailed error messages
- Access `/preview` route to see the generated homepage

### Production Mode (`--production`)
- Optimized, minified build
- Static HTML export
- Faster load times
- Ready for deployment

## Prerequisites

- Node.js 18+ installed
- npm dependencies installed (`npm install` in `web-app/`)
- Generated JSON config files in `output/` directory

## Troubleshooting

### "No config files found" Error

Make sure JSON config files exist in the `output/` directory. Run the Epic 7 generation workflow first to create these files.

### Build Failures

1. Check Node.js version: `node --version` (should be 18+)
2. Reinstall dependencies: `cd web-app && npm install`
3. Check for TypeScript errors: `cd web-app && npx tsc --noEmit`

### Port Already in Use (Dev Mode)

If port 3000 is already in use:
```bash
# Kill existing process
lsof -ti:3000 | xargs kill -9

# Or use a different port
PORT=3001 ./build-from-config.sh --dev
```

## Integration with CI/CD

These scripts can be integrated into CI/CD pipelines:

```yaml
# Example GitHub Actions workflow
- name: Build Hotel Websites
  run: |
    ./scripts/build-from-config.sh --all --production
```

```yaml
# Example GitLab CI
build:
  script:
    - ./scripts/build-from-config.sh --all --production
  artifacts:
    paths:
      - dist/
```
