## Quick Start

This guide will help you get started with using Storybook to develop and document hotel website components.

### Prerequisites

- Node.js 20+ installed
- npm or yarn package manager
- Basic knowledge of React and TypeScript

### Installation

All dependencies are already installed. To start Storybook:

```bash
cd web-app
npm run storybook
```

Storybook will open at [http://localhost:6006](http://localhost:6006)

## Development Workflow

### 1. Creating Component Stories

Stories are created in the `stories/` directory following this structure:

```
stories/
├── 1-Design-System/      # Design token documentation
├── 2-Components/         # Component stories
│   ├── HeroSection/
│   ├── ImageGallery/
│   └── [other components]
└── 0-Introduction/       # Welcome and getting started guides
```

### 2. Story File Template

```tsx
import type { Meta, StoryObj } from '@storybook/react-vite';
import ComponentName from '@/components/ComponentName';

const meta: Meta<typeof ComponentName> = {
  title: 'Components/Category/ComponentName',
  component: ComponentName,
  tags: ['autodocs'],
};

export default meta;
type Story = StoryObj<typeof ComponentName>;

export const Default: Story = {
  args: {
    // Component props
  },
};
```

### 3. Using Design Tokens

All components should use semantic design tokens from Story 1.11:

```tsx
// Brand colors
bg-brand-primary
text-on-brand

// Surface colors
bg-surface-default
bg-surface-elevated

// Text colors
text-text-primary
text-text-secondary

// Spacing
p-section
p-container
```

## Testing Components

### Viewport Testing

Use the viewport addon to test responsive design:

- **Mobile (375px)** - Small phones
- **Tablet (768px)** - Tablets and small laptops
- **Desktop (1280px)** - Standard desktop screens
- **Wide (1920px)** - Large desktop monitors

### Theme Testing

Toggle between light and dark modes using the theme toggle in the toolbar.

### Accessibility Testing

Each story includes an **Accessibility** panel powered by axe-core. Check for:
- Color contrast ratios (WCAG AA)
- ARIA labels
- Keyboard navigation
- Semantic HTML

## Design System Reference

### Typography

- **Display font**: Playfair Display (headings)
- **Body font**: Inter (paragraphs, UI)
- **Mono font**: Fira Code (code)

### Color System (OKLCH)

- **Brand Primary**: oklch(0.346 0.074 256) (deep blue)
- **Brand Secondary**: oklch(0.748 0.099 86.1) (gold)
- **Surface Default**: oklch(1 0 0) (white)
- **Surface Elevated**: oklch(0.984 0.003 247.9) (light gray)
- **Text Primary**: oklch(0.208 0.04 265.8) (dark slate)

Palette shades are auto-generated by `useHotelTheme` using `culori`.

### Spacing

- **p-section**: Section-level padding
- **p-container**: Container padding
- **space-y-4, space-x-4**: Tailwind spacing utilities

## Common Patterns

### Creating Variant Stories

```tsx
export const Small: Story = {
  args: {
    variant: 'small',
  },
};

export const Large: Story = {
  args: {
    variant: 'large',
  },
};
```

### Responsive Stories

```tsx
export const Mobile: Story = {
  ...Default,
  parameters: {
    viewport: {
      defaultViewport: 'mobile',
    },
  },
};
```

### Testing Interactions

```tsx
import { within, expect } from 'storybook/test';

export const WithInteraction: Story = {
  play: async ({ canvasElement }) => {
    const canvas = within(canvasElement);
    const button = canvas.getByRole('button');
    await expect(button).toBeInTheDocument();
  },
};
```

## Troubleshooting

### Storybook won't start

1. Check that all dependencies are installed: `npm install`
2. Verify port 6006 is available
3. Check for TypeScript errors in story files

### Design tokens not loading

1. Verify `.storybook/preview.ts` imports `../app/globals.css`
2. Check that tokens are defined in `globals.css`
3. Clear Storybook cache: delete `node_modules/.cache/storybook`

### Component not rendering

1. Check the component import path
2. Verify component props match story args
3. Check browser console for errors
